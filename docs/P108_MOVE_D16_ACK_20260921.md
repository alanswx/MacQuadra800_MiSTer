Select d16 destination An while the source read waits. At a successful
ordinary source acknowledgement, if the destination extension is resident,
the base selector matches and neither register write port is pending,
consume the extension and calculate the destination address together.
Enter S_PIPE_DEA, which still handles MOVE flags and the ordered store.
Otherwise retain the existing immf/S_EA_D16 path. Source errors and split
reads retain their original paths. No destination memory request occurs
before the successful source acknowledgement.

boundary screening pending. Not qualified or applied.
